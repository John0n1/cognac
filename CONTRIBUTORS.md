# Contributors

Cognac is built and maintained by people contributing code, testing, packaging, documentation, compatibility research, and reproducible bug reports.

## Maintainer

- [John0n1](https://github.com/John0n1) — creator and maintainer

## Contributors

Git history and GitHub's contributor graph are the authoritative record of code contributions.

People who make substantial non-code contributions may also be listed here when appropriate, including:

- compatibility testing across applications and distributions
- packaging and release engineering
- documentation
- reproducible bug investigations
- security reports
- architecture and design work that results in project changes

If you contributed and believe you should be listed here, open a pull request adding your name or handle and a short description of the contribution.

## Attribution

Do not add automated tools, language models, code generators, CI services, or other software as human contributors. Contributions remain attributable to the person who reviews, submits, and takes responsibility for them.

Third-party projects used or integrated by Cognac are credited separately in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
